Deploy (30 min)

4

Deploy to Netlify (free)

Drag-and-drop deploy — SSL included automatically

Before you deploy — folder structure must look like this: The index.html file must be at the ROOT of the folder, not inside /pages/. 
dave-patton-site/
├── index.html          ← main site (copy from pages/index.html)
├── instructions.html   ← this guide
├── llms.txt
├── robots.txt
├── sitemap.xml
├── images/
│   ├── dave-patton-headshot.jpg
│   ├── og-home.jpg
│   └── ... (all image files)
└── schema/
    ├── person.jsonld
    ├── faq.jsonld
    └── breadcrumbs.jsonld
  1. Create a free account at netlify.com
  2. Click "Add new site" → "Deploy manually"
  3. Drag your entire dave-patton-site/ folder onto the upload box
  4. Netlify gives you a random URL like quirky-name-123.netlify.app
  5. Click it — site should be live immediately
Verify these URLs work after deploy:
  • yoursite.netlify.app/ → homepage loads
  • yoursite.netlify.app/llms.txt → shows plain text
  • yoursite.netlify.app/robots.txt → shows plain text
  • yoursite.netlify.app/sitemap.xml → shows XML
5

Connect your custom domain + SSL

Point davepattonrealty.com to Netlify — SSL is automatic

In Netlify dashboard:

  1. Go to your site → Domain management → Add custom domain
  2. Type your domain (e.g. davepattonrealty.com) → Verify
  3. Netlify shows you nameservers — they look like: dns1.p08.nsone.net
  4. Copy all 4 nameservers

In Namecheap dashboard:

  1. Log in → Domain List → Manage (your domain)
  2. Nameservers → select "Custom DNS"
  3. Paste in Netlify's nameservers, one per line
  4. Save
Wait time: DNS propagates in 5 minutes to 48 hours. Usually under 1 hour. Netlify auto-provisions a free SSL certificate once it detects propagation — the padlock will go green on its own.

Verify Everything (30 min)

6

Run the verification checklist

Validate schema, meta, speed, and SSL before submitting to Google

  • Site loads at https://yourdomain.com (padlock shows)
  • https://yourdomain.com/llms.txt returns plain text
  • https://yourdomain.com/robots.txt returns plain text
  • https://yourdomain.com/sitemap.xml returns XML
  • All nav links work (no 404s)
  • Schema validation: validator.schema.org → paste URL → no errors
  • Rich results test: search.google.com/test/rich-results → Person + FAQ detected
  • Meta preview: metatags.io → OG image shows correctly
  • PageSpeed: pagespeed.web.dev → target 90+ mobile
If PageSpeed score is below 80: Images are too large. Compress them at squoosh.app before re-uploading.
4

Submit to Google (15 min)

7

Google Search Console setup

Verify ownership, submit sitemap, request indexing

  1. Go to search.google.com/search-console
  2. Sign in (create a Google account for Dave if needed)
  3. Click "Add property" → URL prefix → enter https://yourdomain.com
  4. Verification method: HTML tag → copy the meta tag 
    <meta name="google-site-verification" content="YOUR_CODE_HERE" />
    Paste it inside the <head> of index.html → redeploy to Netlify → click Verify
  5. Left sidebar → Sitemaps → enter sitemap.xml → Submit
  6. Left sidebar → URL Inspection → type / → Request Indexing
  7. Repeat Request Indexing for: /about/, /services/, /senior-transitions/
Expected timeline: Google typically indexes the homepage within 1-7 days of sitemap submission. The CSHP schema and FAQ schema will start showing in rich results within 2-4 weeks.

ONGOING TASKS (monthly):

GitHub setup for easy ongoing updates (optional but recommended)

Connect GitHub to Netlify so every file change auto-deploys

  1. Create a free account at github.com
  2. Fork this repo: github.com/georgeshamblin/dave-patton-site (click Fork button top-right)
  3. In Netlify: Site settings → Build & deploy → Link repository
  4. Connect GitHub → select your forked repo
  5. Build command: leave blank. Publish directory: / (root)
  6. From now on: edit files directly in GitHub (click pencil icon on any file), commit, Netlify auto-deploys in ~30 seconds
With this setup, the workflow is: Claude writes new content → Dave pastes it into GitHub file editor → commits → site updates automatically. No FTP, no terminal, no dragging and dropping.
